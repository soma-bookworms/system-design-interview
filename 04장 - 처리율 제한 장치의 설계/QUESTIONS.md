실제 토큰 형태는?
- 토큰 버켓 알고리즘 
```
value: [ // fields
  "tokens", "7.0000",    // ts 시점의 잔여 토큰 수
  "ts", "1787879924.551" // 위 잔량을 기록한 시간 (유닉스 초, 소수점은 마이크로초)
]
```
- 솔직히 구현하기 나름
- 위 예시는 토큰 갯수 + 잔여량 기록한 시간을 기준으로 토큰 갯수 갱신
