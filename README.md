# 개요

가상 면접 사례로 배우는 대규모 시스템 설계 기초 스터디

## 기간

- 일정: 2026.08.28 ~ 2026.10.8 / 6회차
  - 추석 제외
  - 10월 9일 스터디 일정을 10월 8일로 이전
- 매주 금요일 20시 대면으로 진행 (변경 예정)

## 인원

총 6명 내외

## 진행 방식

> 1주간 각자 책을 읽고 개인 정리를 진행하고, 스터디 시간에는 주차 별 발표자가 챕터 별 내용을 공유한다.

- 스터디 시간: 1시간 반
- 발표자: 매 회차별 2명
- 서기: 1명 (나온 질문들 정리 / 해당 주차의 발표자 제외)
- 분량
  - 4장 이후부터 진행
  - 매 회차별로 2장씩 진행
- 발표 자료 작성 가이드: [DIRECTION.md](./DIRECTION.md)

## 발표

- 발표자는 본인이 맡은 장에 대한 발표 자료를 준비한다.
- 발표자는 매주 금요일 오전 00시 전에 발표 자료를 업로드한다.
- 발표자 외의 사람은 업로드된 발표 자료에 질문이나 중요하다고 생각되는 부분을 미리 댓글로 남긴다.
- 발표 자료는 약 2시간 이내로 작성할 수 있는 분량으로 한다.
- 발표는 인당 약 10분 이내로 진행한다.
- 발표 준비를 AI에 의존하지 않기 (자아 의탁 X)

## 회고

- 발표 및 의견 교환 후 약 10분간의 회고를 진행한다.
- 책을 읽으면서 느낀 점, 발표 자료를 준비하며 어려웠던 부분 등을 자유롭게 이야기한다.
- 스터디 운영에 대한 의견도 자유롭게 이야기하는 시간을 가진다.
- 편안한 분위기에서 진행한다.
