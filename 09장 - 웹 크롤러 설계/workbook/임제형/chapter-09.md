## 개요

> 로봇robot 또는 스파이더spider 라고도 불리는 웹 크롤러를 설계해보자

## 설계

### 요구사항

- 검색엔진 인덱스 생성 용도의 웹 크롤러
- 웹은 거대하기에 규모 확장성이 높아야 하며
- 함정으로 가득찬 웹에 대응하는 안정성이 있어야 하고
- 대상 사이트를 부하시키지 않는 예절politeness를 가지고
- 여러 콘텐츠를 지원가능한 확장성이 있으면 좋다.

### 데이터 흐름

1. 시작 URL 집합
2. 미수집 URL 저장소
3. HTML 다운로더 -> 도메인 이름 변환기
4. 컨텐츠 파서
5. 중복 컨텐츠 여부 확인 <- 컨텐츠 저장소
6. URL 추출기
7. URL 필터
8. 이미 방문한 URL 여부 확인 <- URL 저장소
9. 2~8 반복

### 상세 설계

- DFS vs BFS
- hostname과 작업 스레드 사이의 관계 유지로 부하 조절하기
- host와 queue를 대응하여, 돌아가면서 큐에서 작업을 가져오도록 설정
- 앞단에 큐 집합을 하나 더 둬서, 우선순위가 높은 페이지를 더 많이 크롤링하도록 설정 가능하다.
